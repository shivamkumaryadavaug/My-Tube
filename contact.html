What we can help with

  • Account support — trouble signing in, guest sessions, or display name/password changes
  • Study progress issues — playlists, completion status, or streaks not behaving as expected
  • Bug reports — anything in the app that isn't working correctly
  • Privacy / data requests — questions about the data described in the Privacy Policy
  • Account deletion requests — you can delete your own account directly from Settings → Danger Zone; contact us only if you need help with that process
  • Copyright / content concerns — questions about YouTube content accessed through MyTube (see Ownership & Credits)
  • Technical support — general help using the app

Before you write in

To help us respond faster, please include your account email (or note that you're using a guest session), the device/app you're using (web or Android), and a short description of the issue.
